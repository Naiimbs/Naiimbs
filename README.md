## What I do

- **Product design:** research, UX strategy, interaction design, and end-to-end product thinking.
- **Design systems:** scalable UI foundations, reusable components, and design-to-code workflows.
- **AI products:** practical AI experiences, agents, retrieval-augmented generation (RAG), and human-centered automation.
